# Private credentials migration

Build `d1_migration` only with the existing private headers. Upload over USB without uploading LittleFS. Never distribute the resulting binary. Confirm serial output `Credentials: persistent configuration ready`, then test existing admin and OTA passwords. Build generic `d1` separately; it contains no private header references outside the excluded migration branch. Upload generic over USB or existing OTA only after migration works. Do not upload a filesystem image. Factory reset currently deliberately preserves credentials to avoid locking out the owner. Fresh-device provisioning and password change/recovery are not implemented yet. Missing or malformed credentials disable maintenance authentication and ArduinoOTA; recover using USB and a valid private migration build (invalid existing records require separate physical recovery). Local HTTP Basic and plaintext LittleFS are not encryption. Firmware publication remains disabled.
